# 🌐 Portfólio Pessoal - Thauany Gabrielli

Este repositório contém o código-fonte da página de portfólio pessoal desenvolvida por **Thauany Gabrielli Silva Zoia**, estudante de Desenvolvimento de Sistemas no SENAI. O projeto foi construído para apresentar habilidades técnicas, listar projetos acadêmicos e disponibilizar um formulário de contacto.

---

## 📌 Seções do Portfólio

* **Navegação Principal:** Links para navegar até às secções da página (`#sobre`, `#Projetos`, `#contato`).
* **Sobre Mim:** Apresentação pessoal, foto de perfil e lista de competências técnicas.
* **Projetos:** Tabela com os trabalhos desenvolvidos, tecnologias utilizadas, estado e hiperligações para os repositórios.
* **Contacto:** Formulário interativo para envio de mensagens com validação de campos (`required`) e menu de seleção.
* **Rodapé:** Créditos do curso SENAI e contactos diretos (e-mail e telefone).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação das secções (`<nav>`, `<section>`, `<footer>`, `<fieldset>`, `<table>`).
* **CSS3:** Estilização e estrutura visual.
* **PHP / Figma:** Tecnologias aplicadas nos projetos apresentados.
